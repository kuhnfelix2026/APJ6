# CarreraUdpTest: slot car cruise control

A Simulink model runs on the car (SAMD21 board) and holds a target speed with a PI controller. Python programs on the laptop send target speeds over Wi-Fi (UDP port 2390) and log what the car sends back.

## Folder layout

| Path | What it is |
|---|---|
| `CarreraUdpTest.slx` | The Simulink model. This is what you edit. |
| `CarreraUdpTest.slx.r2025a` | Copy of the model saved for MATLAB R2025a. |
| `APJ6_interface.h`, `apj6_car.a` | The car library (Wi-Fi, sensors, motor) called from the model's C Caller blocks. Don't change. |
| `apj6_execute_testcase.py` | Plays a scripted test from `control.csv` and logs the result. |
| `apj6_live_control.py` | Web page with a slider to set the target speed live. |
| `control.csv` | The test script: one row per step. |
| `logs/` | Result logs: `control_XX.csv` from test runs, `live_XX.csv` from live control. |
| `CarreraUdpTest_ert_rtw/`, `slprj/`, `CarreraUdpTest.slxc`, `.elf`, `.bin` | Generated by Simulink when you build. Safe to delete; rebuilt every time. |

## Running a test

1. Start the laptop hotspot the car connects to.
2. In Simulink: build and deploy to the car (Hardware tab).
3. Run the test:
   ```
   python apj6_execute_testcase.py control.csv --echo
   ```
   Always use `--echo`. Without it the car only gets a packet when a step starts, and stops after 2 s without commands.
4. The log appears in `logs/` as the next free `control_XX.csv`.

Or for live control: `python apj6_live_control.py`, then use the page that opens at http://localhost:8000. Don't run both programs at once.

## control.csv format

```
delay, set_speed, set_distance, a, b, c, d, e
3000,        110,            0, 0, 0, 0, 0, 0
2000,          0,            0, 0, 0, 0, 0, 0
```

- `delay`: how long this step lasts, in ms.
- `set_speed`: target speed ÷ 10 (the model multiplies by 10, so 110 means 1,100).
- Keep targets at or below about 125 (1,250); the car tops out around 1,300–1,370 at power 150.
- End with a `0` row so the car stops.
- No blank lines: a blank line repeats the previous step for another delay.

## Model in short

- Target = `set_speed` × 10, measured speed from `APJ6_Car_get_speed`.
- Discrete PI controller, sample time 0.05 s, P = 0.1, I = 0.5, output limited to 0–150 with clamping anti-windup.
- The PID resets while the target is 0 or when the library raises `reset`.
- `C Caller output` sends back: a = distance, b = set_speed, c = PID power, d = input a, e = battery voltage.
